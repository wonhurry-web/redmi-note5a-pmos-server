# 00 · 快速复现指南

> 面向同型号（Redmi Note 5A / ugglite / `qcom-msm89x7`）设备的从零复现步骤。
> 这是权威入口；更细的背景与排错见 `docs/01`–`docs/07`。

---

## 约定

- 下文所有 `<...>` 占位符替换为**你自己的值**（见根 README「脱敏说明」）。
- 构建在 **Linux / WSL2** 完成；刷机在 **Windows**（adb/fastboot）完成，因为 USB 直通 WSL 不可靠。
- 全程需要稳定网络；国内直连 pmaports 镜像很慢，建议配置代理。

---

## 阶段 0：解锁与备份（不可跳过）

1. 开启开发者选项 → USB 调试；`adb devices` 确认设备在线。
2. 确认 Bootloader 已解锁：
   ```bash
   adb shell getprop ro.boot.verifiedbootstate   # 应为 orange
   ```
   未解锁需走小米官方解锁流程。
3. 备份用户数据（本机 bootloader 不支持 `fastboot dump_image`，只能 pull）：
   ```bash
   adb pull /sdcard/ ./backup/sdcard/
   ```
4. 准备回滚手段：下载对应机型的**小米官方线刷包 + Mi Flash**（刷机失败时恢复）。

---

## 阶段 1：构建 postmarketOS 镜像

在 WSL2 / Ubuntu 中：

```bash
# 1. 依赖
sudo apt install -y python3-pip python3-venv git kpartx adb fastboot

# 2. pmbootstrap 源码安装（PyPI 版本已被 yanked，必须从 GitLab 源码装）
git clone --depth 1 https://gitlab.postmarketos.org/postmarketOS/pmbootstrap.git ~/pmbootstrap
python3 -m venv --system-site-packages ~/pmb-venv && source ~/pmb-venv/bin/activate
pip install -e ~/pmbootstrap

# 3. sudo 免密（否则 pmbootstrap 调 losetup 会超时）
echo "$USER ALL=(ALL) NOPASSWD: ALL" | sudo tee /etc/sudoers.d/pmbootstrap-nopasswd
sudo chmod 440 /etc/sudoers.d/pmbootstrap-nopasswd
```

写 `~/.config/pmbootstrap_v3.cfg`（模板见 `config/pmbootstrap_v3.cfg.example`），关键字段：

```ini
[pmbootstrap]
device = qcom-msm89x7
kernel = edge
ui = none
extra_packages = openssh,networkmanager,avahi,docker,tmux,htop,nano,curl,wget,wpa_supplicant,wpa_supplicant-openrc,msm-firmware-loader-wcnss
hostname = note5a-srv
service_manager = openrc
timezone = Asia/Shanghai
```

⚠️ 三个必须注意的包（缺一不可，详见 `docs/06` 坑 16）：
- `wpa_supplicant` + `wpa_supplicant-openrc`：WPA 认证后端
- `msm-firmware-loader-wcnss`：从 Android persist 分区提取本机 WCNSS Wi-Fi 固件，否则 wlan0 永远 DOWN

构建：

```bash
printf '\n%.0s' {1..25} | python3 -u ~/pmbootstrap/pmbootstrap.py init --shallow-initial-clone
python3 -u ~/pmbootstrap/pmbootstrap.py install --password <TEMP_PASSWORD> \
  --add "openssh,networkmanager,avahi,docker,tmux,htop,nano,curl,wget,wpa_supplicant,wpa_supplicant-openrc,msm-firmware-loader-wcnss"
python3 -u ~/pmbootstrap/pmbootstrap.py export
```

> 若卡在 45 MB 内核包下载中断（镜像站问题），见 `docs/06` 坑 12 的代理补全方案。

## 阶段 2：离线修改镜像（关键）

刷机前把配置写进镜像 rootfs，避免首启无网络无法配置。用 `kpartx` 挂载：

```bash
sudo kpartx -av qcom-msm89x7.img          # 生成 loop0p1(/boot) loop0p2(rootfs)
sudo mount /dev/mapper/loop0p2 /tmp/mnt
# ... 按 config/ 模板放入 /etc/local.d/、Wi-Fi 配置、inittab ...
sudo umount /tmp/mnt && sudo kpartx -d qcom-msm89x7.img
```

至少完成三件事（详见 `docs/07`）：

1. **开机自动连 Wi-Fi**：`config/50-wifi.start` + `config/wpa-auto.conf.example`
2. **USB 串口应急通道**：`/etc/inittab` 加 `ttyGS0` getty，并启用 ACM gadget
3. **NetworkManager 加入 default runlevel**（若走 NM 路线）：
   ```bash
   sudo ln -s /etc/init.d/networkmanager /tmp/mnt/etc/runlevels/default/networkmanager
   ```

## 阶段 3：刷机

手机进入 fastboot（关机后按住音量下+电源，或 `adb reboot bootloader`），在 Windows 侧：

```bat
fastboot flash boot lk2nd.img
fastboot flash userdata qcom-msm89x7.img
fastboot reboot
```

- `lk2nd.img` 由 pmbootstrap 导出时自带，**必须先刷**，否则主线内核识别不了屏幕会黑屏。
- rootfs 刷到 `userdata` 分区（本机 10 GB，足够）。

---

## 阶段 4：首启联网与 SSH

开机后用 USB 串口登录（无需网络、免驱动签名）：

- Windows 设备管理器出现 `USB\VID_1D6B&PID_0104` 的 COM 口（本机为 `<COM_PORT>`）
- 串口参数：115200 / 8N1 / 无流控
- 登录：安装时设的用户与 `<TEMP_PASSWORD>`

确认联网：

```bash
ip -4 addr show wlan0           # 应拿到 IP
ping -c2 <GATEWAY_IP>
```

SSH 免密（在 Windows 客户端）：

```bash
ssh-keygen -t ed25519           # 若还没有密钥
# 把 ~/.ssh/id_ed25519.pub 内容追加到设备 /home/user/.ssh/authorized_keys（600）
ssh -i ~/.ssh/id_ed25519 user@<DEVICE_IP>
```

首启后立即改密码：`passwd`，需要 root 再 `sudo passwd root` 并按需开放 `/etc/ssh/sshd_config`。

## 阶段 5：仪表盘与电源键

在设备上：

```bash
apk add gcc musl-dev
# 上传 dashboard/pmos-dash.c、pwrkey-blank.c 到设备编译安装（详见 dashboard/README.md）
/etc/local.d/70-dashboard.start
/etc/local.d/80-pwrkey.start
sudo reboot
```

开机即进入仪表盘；短按电源键切屏。效果见 `dashboard/preview-v3.png`。
