# 01 · 设备诊断报告

> 采集时间：2026-11-19
> 采集方式：通过 ADB（`D:\platform-tools\adb.exe`，版本 36.0.0）连接真机实测

---

## 1. ADB 连接状态

```
$ adb devices -l
<DEVICE_SERIAL>               device product:lineage_Mi8917 model:Redmi_Note_5A device:ugglite transport_id:2
<DEVICE_IP>:5555    device product:lineage_Mi8917 model:Redmi_Note_5A device:ugglite transport_id:3
```

- **USB 通道**：序列号 `<DEVICE_SERIAL>`，已授权，稳定可靠 —— 推荐用于刷机与救援。
- **无线通道**：`<DEVICE_IP>:5555`（`service.adb.tcp.port = 5555`），同一局域网可用 —— 适合无数据线场景。
- 两个通道均为 `device` 状态，说明驱动、授权均正常。

> 本报告中命令默认使用 `-s <DEVICE_SERIAL>` 指定 USB 设备，避免多设备歧义。

## 4. 内存与存储

```
$ free -h
              total        used        free
Mem:            1.7G        1.6G        107M

$ df -h /data
Filesystem            Size  Used Avail Use% Mounted on
/dev/block/mmcblk0p48  10G  5.3G  4.4G  55% /data
```

- 内存 2GB（可用约 1.7G）：**服务器用途偏紧**，需选轻量软件栈（见 `docs/03`）。
- `/data` 实际 10GB，已用 5.3GB，可用 4.4GB —— 刷机前需确认备份空间充足。

## 5. 分区布局

```
$ ls -l /dev/block/bootdevice/by-name/
aboot     -> /dev/block/mmcblk0p19    (bootloader)
abootbak  -> /dev/block/mmcblk0p20
boot      -> /dev/block/mmcblk0p21    (内核 + ramdisk，刷 lk2nd/kernel 的目标)
recovery  -> /dev/block/mmcblk0p22
system    -> /dev/block/mmcblk0p24
cache     -> /dev/block/mmcblk0p25
persist   -> /dev/block/mmcblk0p26
misc      -> /dev/block/mmcblk0p27
userdata  -> /dev/block/mmcblk0p48    (pmOS rootfs 默认刷入此处)
```

标准高通 AOSP 分区布局，`pmbootstrap flasher` 可自动识别。

## 6. Bootloader 状态

```
$ getprop ro.boot.verifiedbootstate
orange
```

`orange` = **Bootloader 已解锁**，允许刷写自定义镜像。这是刷入 postmarketOS 的硬性前提，✅ 已满足。
